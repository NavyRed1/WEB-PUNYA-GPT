ITS Campus Care — Updated Prototype

Open ITS_Campus_Care_Prototype.html in a modern browser.
Create a report from Submit a Report, then open My Reports and click a report card.
In the detail panel, use “Simulasikan Update Status” to move Pending -> In Progress -> Resolved. “Reset ke Pending” lets you repeat the demo.

My Reports and the Overview's recent reports are automatically sorted by the latest status update (newest first). Each report shows both its creation date/time and its latest update date/time. Status colors: Pending = yellow, In Progress = blue, Resolved = green.

Important: This is a frontend-only demonstration. Reports are stored in localStorage in the current browser; no live ITS backend is connected. The status simulation is for UI testing only and should be replaced by authenticated staff/backend updates in production.
